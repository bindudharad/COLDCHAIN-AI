# Original Downloads Archive

This directory stores the original, unmodified downloaded archives from public dataset sources.

## Policy
- **NEVER** modify files in this directory
- Original ZIP/CSV files should be preserved exactly as downloaded
- Processed or transformed versions belong in their respective numbered subdirectories
- File integrity can be verified using checksums recorded in `docs/SOURCE_PROVENANCE.md`

## Contents
Place original downloaded dataset files here with their original filenames.
