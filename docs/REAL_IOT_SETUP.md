## 1. Architectural Scope & Safety Safeguards

> [!CAUTION]
> **ACTUATION HARDWARE BOUNDARY:**  
> The COLDCHAIN-AI platform provides **advisory decision-support setpoints**. The optimizer must **NEVER** be wired directly to high-voltage compressor contactors, relays, or industrial PLCs without dual redundant physical thermal cutoffs, hardwired safety thermostats, and licensed refrigeration technician certification.

### Data Provenance Segregation
Every sensor reading ingested into the database is tagged with its provenance classification:
1. `REAL_SENSOR`: Telemetry originated from physical on-site sensor hardware (e.g. ESP32, Raspberry Pi, industrial 4–20 mA transmitter).
2. `PUBLIC_DATASET`: Historical static data downloaded from public research repositories (e.g. Kaggle ESP8266 or HVAC studies).
3. `SIMULATION`: Synthetic thermal dynamics generated by calibrated physical simulation models (`data/raw/simulated_cold_chain.csv`).

## 2. Telemetry Ingestion API Specification

- **Endpoint:** `POST /api/iot/telemetry/`
- **Authentication:** Header `X-IoT-API-Key: coldchain-iot-dev-key` (or configured deployment key).
- **Content-Type:** `application/json`

### 2.1 Single Telemetry Packet Payload
```json
{
  "sensor_id": "EDGE-ESP32-01",
  "timestamp": "2026-10-09T14:30:00Z",
  "temperature": 3.75,
  "temperature_unit": "C",
  "humidity": 68.5,
  "ambient_temperature": 22.4,
  "power_kw": 0.48,
  "compressor_state": true,
  "door_open": false,
  "location": "Cold Room Warehouse Bay 3",
  "product_type": "Food",
  "data_source": "REAL_SENSOR"
}
```

### 2.2 Ingestion Validation Rules
| Field | Type | Validation & Range Checks |
| :--- | :--- | :--- |
| `sensor_id` | String | Required. Alphanumeric identifier (max 64 chars). Auto-registered if new. |
| `timestamp` | ISO-8601 | Required. Valid RFC-3339 / ISO format. Duplicates for same sensor are rejected with `duplicates_ignored: 1`. |
| `temperature` | Float | Required. Range: $[-60.0, +70.0]\text{ }^\circ\text{C}$. Out-of-range sensor spikes are rejected (HTTP 400). |
| `temperature_unit` | String | Optional (`"C"` or `"F"`). If `"F"`, automatically converted to Celsius: $T_C = (T_F - 32) \times 5/9$. |
| `humidity` | Float | Optional. Range: $[0.0, 100.0]\%$. |
| `ambient_temperature` | Float | Optional. Range: $[-60.0, +75.0]\text{ }^\circ\text{C}$. |
| `power_kw` | Float | Optional. Range: $[0.0, 100.0]\text{ kW}$. |
| `data_source` | String | Must be `REAL_SENSOR`, `SIMULATION`, or `PUBLIC_DATASET`. Defaults to `REAL_SENSOR`. |

### 2.3 Response Formats
- **Success (HTTP 201 Created):**
  ```json
  {
    "success": true,
    "records_received": 1,
    "records_valid": 1,
    "records_persisted": 1,
    "duplicates_ignored": 0,
    "errors": [],
    "provenance": "REAL_SENSOR",
    "status": "INGESTED",
    "latest_id": 12008
  }
  ```
- **Validation Failure (HTTP 400 Bad Request):**
  ```json
  {
    "success": false,
    "errors": ["Record 0: Temperature -85.00 °C out of physical range [-60, +70] °C."],
    "records_processed": 0
  }
  ```

## 3. Physical Hardware Firmware Examples

### 3.1 ESP32 Microcontroller (Arduino C++)
```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>
#include <DHT.h>

const char* ssid = "COLDCHAIN_WIFI";
const char* password = "WarehousePassword";
const char* serverUrl = "http://192.168.1.100:8000/api/iot/telemetry/";
const char* apiKey = "coldchain-iot-dev-key";

#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println("\nWiFi Connected");
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    float temp = dht.readTemperature();
    float hum = dht.readHumidity();
    
    if (!isnan(temp) && !isnan(hum)) {
      HTTPClient http;
      http.begin(serverUrl);
      http.addHeader("Content-Type", "application/json");
      http.addHeader("X-IoT-API-Key", apiKey);
      
      StaticJsonDocument<256> doc;
      doc["sensor_id"] = "ESP32-BAY-01";
      doc["temperature"] = temp;
      doc["temperature_unit"] = "C";
      doc["humidity"] = hum;
      doc["ambient_temperature"] = 24.5;
      doc["data_source"] = "REAL_SENSOR";
      
      String jsonStr;
      serializeJson(doc, jsonStr);
      int httpCode = http.POST(jsonStr);
      Serial.printf("POST status: %d\n", httpCode);
      http.end();
    }
  }
  delay(60000); // Sample every 60 seconds
}
```
